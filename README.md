# Qubes Colorful Frames for KDE Breeze (obsolete)

This repository is obsolete. Its contents were merged into
[qubes-desktop-linux-kde](https://github.com/QubesOS/qubes-desktop-linux-kde).

It colored the KDE window frames of each qube's windows with that qube's label
color. On login, `qubes-generate-color-palette` read the qube labels and wrote
a [Breeze](https://invent.kde.org/plasma/breeze) color scheme per label.
